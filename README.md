# My-Portfolio

A personal portfolio website designed with a minimal, analog "fieldnote" aesthetic to document my front-end development learning journey.

I built this project to move away from generic, ultra-modern tech templates and instead focus on typography, editorial layouts, and handling responsive web design using vanilla CSS.

## About the project

This is a small portfolio project documenting my progress as I learn web development.

The site includes:

- An introduction
- About section
- Selected projects
- Skills and tools
- Contact links

The layout uses a fixed sidebar on larger screens and adapts to smaller screens with a responsive navigation layout.

## Built with

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Responsive Design
- Google Fonts
- GitHub Pages

## Design

The visual direction is inspired by old field notes and printed pages.

I used:

- A warm paper-like background
- Serif typography for headings
- Monospace text for smaller details
- Dashed borders
- Muted green, brown, and rust tones
- A simple sidebar navigation

The goal was to keep the interface quiet and readable rather than filling it with unnecessary elements.

## What I learned

While building this project, I worked on:

- Building a complete page layout with CSS Grid
- Combining Grid and Flexbox
- Creating responsive layouts with media queries
- Working with typography and spacing
- Using CSS custom properties
- Structuring a multi-section website
- Publishing a project with GitHub Pages
